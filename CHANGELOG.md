## Оптимизация стабильности и скорости

- **Whisper:** при лимите ожидания загрузки следующая попытка не стартует параллельно — дожидаемся завершения потока (без двойной загрузки в RAM).
- **Streamlit:** `Transcriber` с загруженным Whisper кешируется на **сессию** (`st.cache_resource`, `scope="session"`); `skip_first_seconds` задаётся перед каждым файлом.
- **Google Sheets:** кеш открытого листа по отпечатку ключа + ID таблицы + листа; при ошибке записи — сброс кеша и **одна** повторная попытка; сброс из админ-панели при смене таблицы/листа/ключа.
- **Локальный пунктуатор:** один рабочий поток (`ThreadPoolExecutor` max_workers=1) вместо неограниченных фоновых daemon после wall-timeout.

## Beta 1.0 · 23 марта 2026

**Запуск работы:** первый публичный билд интерфейса для операторов ЕКЦ: локальный анализ звонков через Streamlit, единая точка входа для транскрибации, QA и выгрузки в Google Таблицу. Считается тестовой (beta) веткой — возможны доработки по обратной связи.

### Основной функционал

- Веб-интерфейс **Streamlit** (`web_gui.py`): одиночный файл и пакетная обработка, выбор оператора, отчёты в папку `результаты/`.
- **Распознавание речи:** `faster-whisper`, профили `medium_ru` / `ideal_ru`, по умолчанию в UI — режим **«Максимум»** (Large-v3 + `ideal_ru`).
- **Оценка диалога:** локально (`CallQualityEvaluator`) и/или **Yandex AI Studio** (облачная оценка и пост-редактирование транскрипта).
- **Экспорт в Google Таблицу** при настроенном сервисном ключе (`keygoogle.json` / переменные окружения).
- **Админ-панель** в сайдбаре: смена ключа Yandex, Folder ID и ссылки/ID таблицы с записью в `.env` (доступ по паролю).

### Изменения в этой версии

- Зафиксированы зависимости и сценарий быстрого старта (venv, `requirements.txt`).
- Документация: README, `.env.example`, подсказки в UI; этот файл — **история версий**.
- Версия отображается в шапке сайдбара Streamlit (константы `APP_VERSION_*` в `web_gui.py`).
- Убрана возможность менять ключ API Яндекса и таблицу Google из обычного сайдбара — только через админ-панель.
