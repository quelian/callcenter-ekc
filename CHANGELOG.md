# История изменений

Формат: **версия** · дата · кратко о назначении релиза, затем основной функционал и заметные изменения.

## Ultima +15% ASR качество + максимальная точность диаризации

### ASR (transcription.py)
- **Спектральный денойз** (`_spectral_denoise_audio`): spectral subtraction + Wiener floor перед
  нормализацией — SNR↑ для тихой и шумной речи, Whisper получает чистый сигнал.
- **Decode params**: `beam_size 8→10`, `best_of 4→5`, `patience 1.05→1.1`.
- **Температурная цепочка**: 3 шага → **4 шага** `(0.0, 0.2, 0.4, 0.6)` — больше попыток на
  сложных сегментах.
- **Пороги**: `no_speech_threshold 0.75→0.82`, `log_prob_threshold -1.1→-1.2`,
  `compression_ratio_threshold 2.4→2.5` — Whisper декодирует тихие вступления, не пропускает их.
- **VAD**: `speech_pad_ms 1500→2000` — голосовые зоны расширяются на 2 с, слова у границ не режутся.
- **Сегментация**: `min_silence_gap 0.35→0.25` для Ultima — больше подсегментов → точнее диаризация.

### Диаризация (speaker_diarization_heavy.py)
- **Плотные окна**: шаг `1.0→0.6 с`, минимум `0.8→0.6 с` — 1.7× больше embedding-точек на смену спикера.
- **top_db=24** (было 28) — heavy режим ещё чувствительнее, не срезает шёпот.
- **Взвешенное голосование**: вес окна = его длительность (было: +1 счёт).
- **Временно̀е сглаживание** (`_temporal_smooth_labels`): убирает короткие «острова» не того кластера.
- **min region 0.30→0.25 с**, **merge gap 0.22→0.15 с** — ловим очень короткие реплики.

### Диаризация (speaker_voice_roles.py — лёгкий режим)
- **top_db 35→28** — не срезаем тихую речь.
- **hop_sec 2.0→1.0** (50% перекрытие) — вдвое больше embedding-точек по временно̀й оси.
- **MIN_WINDOWS лимит 180→300** для длинных записей.
- **Min region 0.35→0.25 с** — ловим «да», «нет», короткие реплики.
- **Взвешенный vote**: по длине перекрытия (было: подсчёт окон).
- **Качество кластеров**: порог `1.05→1.3` — при плохом разделении используется time-aware split.
- **A-B-A сглаживание**: порог `0.8→1.5 с` + 2 прохода (было 1 проход).

## LLM пост-редактор: autofix оператор-формулы вместо fallback

- **`llm_post_edit.py`:** добавлена функция `_auto_fix_applicant_closing` — если LLM поместил
  формулу «спасибо вам за обращение» / «благодарим за обращение» под метку **«Заявитель:»**,
  реплика **автоматически переносится** к **«Оператор:»** вместо полного отброса ответа LLM
  (`fallback:validation:applicant_has_operator_closing_formula`).
- Диагностическая заметка `ok:autofix_operator_closing` логируется при каждом таком исправлении.

## Роли Ultima: лучшая диаризация + UI по умолчанию

- **`web_gui.py`:** режим **Ultima** теперь **выбран по умолчанию** (первый в списке radio).

- **`transcription.py`:** для `ultima_ru` **word timestamps включены по умолчанию** — сегменты режутся по паузам между словами (`_split_segment_at_silences`), каждый суб-сегмент точнее принадлежит одному спикеру. Ускорить при необходимости: `CALLQA_ASR_WORD_TIMESTAMPS=0` в `.env`.

- **`speaker_diarization_heavy.py`** — три улучшения:
  - **Кешированная ECAPA-модель:** теперь импортирует `_load_ecapa_model()` / `_embed_windows_ecapa()` / `_normalize_rows()` из `speaker_voice_roles.py` — нет повторной загрузки модели, **используется MPS на M1** вместо CPU.
  - **Батчевый инференс:** все окна обрабатываются одним вызовом вместо цикла — в разы быстрее на M1.
  - **`top_db=28`** (было 35) и мин. длина региона **0.30 с** (было 0.40) — VAD не обрезает тихие короткие реплики («алло», «да»).
  - **`cluster_quality`** теперь возвращается в диагностике heavy diarization (было только у light-пути).

## SpeechBrain / torchaudio (macOS, torchaudio 2.2+)

- Модуль `speechbrain_compat.py`: до импорта SpeechBrain подставляет `torchaudio.list_audio_backends` → `["soundfile"]`, чтобы не было ложного предупреждения «no working backend» (раньше заглушка возвращала `[]`).
- В начале `web_gui.py` вызывается `apply_speechbrain_environment()` — плюс фильтр шумных `UserWarning` (редирект `speechbrain.pretrained`), `FutureWarning` (`torch.cuda.amp.custom_fwd` внутри SpeechBrain) и **`UserWarning` из `torch.functional.stft`** (deprecated resize пустого `out`). Тот же блок **`suppress_noisy_third_party_warnings()`** вызывается при импорте **`transcription.py`** (CLI без Streamlit).
- **Streamlit:** в `web_gui.py` вместо устаревшего `use_container_width=True` используется **`width="stretch"`** (кнопки, таблицы, Plotly, download).
- В `requirements.txt` явно указан `soundfile`.

## ASR: не терять первые секунды диалога (после корректной обрезки ожидания)

- **Анализ:** `docs/ASR_START_ANALYSIS.md` — VAD Silero, первое окно Whisper ~30 с и `no_speech_threshold`, pre-roll, fade, фильтр промпта.
- **Pre-roll:** при `skip>0` загрузка с `offset = skip - CALLQA_ASR_PRE_ROLL_SECONDS` (по умолчанию 0.25 с); **`time_offset` = этот offset** для таймкодов. `CALLQA_ASR_PRE_ROLL_SECONDS=0` — как раньше (рез ровно в `skip`).
- **Fade-in** после обрезки ожидания на нормализации **отключён** (не глушить первый слог).
- **Имя `_MM-SS`:** пропуск по имени без порога (кроме `CALLQA_DISABLE_FILENAME_SKIP=1`).
- **Фильтр промпта:** первые **32 с** WAV не режутся по overlap с `initial_prompt`.
- **VAD ideal_ru:** чувствительнее `medium_ru`, без экстремальных порогов; **medium_ru:** заданы `no_speech_threshold` / `log_prob_threshold`.
- **Аварийно:** `CALLQA_ASR_NO_VAD=1`.

## Логи пайплайна распознавания

- В `transcription.Transcriber` добавлен единый префикс **`[этап: …]`** для этапов: старт, ASR-модель, параметры, пропуск ожидания, подготовка WAV, Whisper, сбор текста, роли/ECAPA/heavy, LLM и локальный пост, сборка отчёта, тональность, готово.

## ASR: нормализация громкости перед Whisper

- Перед распознаванием: **16 kHz mono**; **пропуск ожидания** — `librosa.load(..., offset=skip)` + временный WAV. **Нормализация только по хвосту** (после обрезки): снятие DC, оценка уровня по **речевым кадрам** (не тянуть тишину к целевому RMS), усиление к ~0.11, пик-лимит, короткие косинусные фейды на краях. **`clip_timestamps`** только если WAV не создать. Диаризация и тон — по **исходному** файлу, таймкоды ASR +`skip`.

## ASR: этап «текст / обход сегментов»

- Отдельный этап **убран** — это был тот же потоковый декод Whisper; сообщение перенесено в этап **Whisper**.
- Ускорение декода: **`CALLQA_ASR_WORD_TIMESTAMPS=0`** отключает word-level timestamps (меньше нагрузки; IVR/фильтр промпта остаются на уровне сегмента).

## Streamlit: прогресс и ETA

- Шаги и полоса прогресса снова привязаны к логам **`[этап: …]`** из `transcription.py` (старые фразы «загружаю модель» / «обработано сегментов» больше не встречаются).
- Таймер: при **0%** — пояснение про долгую загрузку модели; при **1–5%** — «уточняется» вместо завышенного «осталось»; иначе экстраполяция с потолком **1 ч**.

## LLM-постредактор ролей и текста

- Промпты в **`llm_post_edit.py`**: жёсткое правило — формулы **«спасибо вам за обращение»** / **«благодарим за обращение»** только у **Оператор**; чеклист в user-prompt; валидация отклоняет ответ, если эти фразы оказались у **Заявитель** (см. **`docs/CALL_CENTER_ROLE_ANCHORS.md`**).
- Remote: чуть ниже `temperature`, выше `max_tokens`; embedded DeepSeek: `max_new_tokens` до 4096 для длинных звонков.
- Эвристики **`transcription.py`**: расширены якоря оператора и закрытие линии (варианты благодарности за обращение).

## Ребаланс ASR-пресетов под Mac M1 8GB

Все три режима переработаны для оптимального соотношения скорость/качество на CPU без GPU.

**Стандарт (`medium_ru`):**
- beam **5** / best_of **3** / patience **0.9** (было 8/6/1.15); **word timestamps выкл.** по умолчанию.
- Оценка: ~1–3 мин на 3-мин запись.

**Максимум (`ideal_ru`):**
- beam **9** / best_of **5** / patience **1.12** (было 11/8/1.16); цепочка температур сокращена до **(0.0, 0.4, 0.8)** (было 6 шагов); word timestamps вкл.
- compute_type в UI → **`int8_float32`** (явно; `float16` всё равно переключался в int8_float32 на CPU).
- Оценка: ~12–22 мин на 3-мин запись.

**Ultima (`ultima_ru`):**
- beam **8** / best_of **4** / patience **1.05**; цепочка температур **(0.0, 0.3, 0.6)** — 3 шага; **word timestamps выкл.** по умолчанию.
- compute_type → **`int8_float32`**; heavy_mode=True; таймаут диаризации в UI по умолчанию **150 с**.
- **Отдельный сверхчувствительный VAD `_vad_ultima`:** threshold **0.12**, neg_threshold **0.06**, speech_pad **1500 мс** — ловит тихое «алло»/«здравствуйте» с первой секунды.
- **no_speech_threshold поднят до 0.75** — Whisper пытается декодировать тихие вступительные фрагменты вместо их пропуска.
- **Нормализация громкости: target_active_rms=0.13** (вместо 0.11 у других профилей) — тихая речь сильнее усиливается перед VAD и Whisper.
- Оценка: ~6–12 мин на 3-мин запись.
- Word timestamps вкл.: `CALLQA_ASR_WORD_TIMESTAMPS=1` в `.env`.

## ASR «Ultima» (`ultima_ru`)

- Профиль **`ultima_ru`**: модель по умолчанию **`bzikst/faster-whisper-large-v3-russian`** (CTranslate2, fine-tuned Russian); переопределение: **`CALLQA_WHISPER_MODEL_ULTIMA`**.
- В **Streamlit** третий режим качества: **Ultima**; VAD + hotwords как у premium; decode — облегчённый пресет (см. ребаланс выше); тяжёлая диаризация включена.
- **HF Hub:** общий lock + контекст `force_huggingface_hub_online()`: у `huggingface_hub` флаг `constants.HF_HUB_OFFLINE` задаётся **при импорте** и не обновляется от `os.environ` — после прогрева ECAPA сеть оставалась «выключенной». Теперь при загрузке Whisper патчится `constants.HF_HUB_OFFLINE=False`; ECAPA восстанавливает прежнее значение или пересчитывает из env (`recompute_huggingface_hub_offline_from_env`).

## ASR «Максимум» (ideal_ru)

- **Качество large-v3:** VAD ideal_ru смягчён (меньше шума в потоке); пороги **`log_prob` −1.0**, **`compression_ratio` 2.4**; убраны **`repetition_penalty` / `no_repeat_ngram`** (мешали естественным повторам в звонках).
- **Логи прогресса:** после подготовки — длительность; затем **каждые ~6 с** и на первом сегменте — «ASR прогресс»; `asr_elapsed` включает декодирование.
- `hotwords`, кавычки «», `initial_prompt`, анти-галлюцинации по промпту.

## Оценка: зона повышенного внимания (Егор, Артем, Даша)

- Те же формальные критерии и чек-лист; для этих операторов: в облаке — доп. блок в промпте при **ручном** выборе оператора (пограничные баллы выше, меньше и мягче negatives); после оценки — **+1** к каждому из четырёх критериев (не выше 10) и пересчёт итога; сокращение списка negatives и усиление positives.
- Локальная эвристика (`CallQualityEvaluator`) и fallback после ошибки API — та же постобработка по каноническому имени оператора.

## Оптимизация стабильности и скорости

- **Whisper:** при лимите ожидания загрузки следующая попытка не стартует параллельно — дожидаемся завершения потока (без двойной загрузки в RAM).
- **Streamlit:** `Transcriber` с загруженным Whisper кешируется на **сессию** (`st.cache_resource`, `scope="session"`); `skip_first_seconds` задаётся перед каждым файлом.
- **Google Sheets:** кеш открытого листа по отпечатку ключа + ID таблицы + листа; при ошибке записи — сброс кеша и **одна** повторная попытка; сброс из админ-панели при смене таблицы/листа/ключа.
- **Локальный пунктуатор:** один рабочий поток (`ThreadPoolExecutor` max_workers=1) вместо неограниченных фоновых daemon после wall-timeout.

## Beta 1.0 · 23 марта 2026

**Запуск работы:** первый публичный билд интерфейса для операторов ЕКЦ: локальный анализ звонков через Streamlit, единая точка входа для транскрибации, QA и выгрузки в Google Таблицу. Считается тестовой (beta) веткой — возможны доработки по обратной связи.

### Основной функционал

- Веб-интерфейс **Streamlit** (`web_gui.py`): одиночный файл и пакетная обработка, выбор оператора, отчёты в папку `результаты/`.
- **Распознавание речи:** `faster-whisper`, профили `medium_ru` / `ideal_ru` / `ultima_ru`, по умолчанию в UI — **«Максимум»** (Large-v3 + `ideal_ru`).
- **Оценка диалога:** локально (`CallQualityEvaluator`) и/или **Yandex AI Studio** (облачная оценка и пост-редактирование транскрипта).
- **Экспорт в Google Таблицу** при настроенном сервисном ключе (`keygoogle.json` / переменные окружения).
- **Админ-панель** в сайдбаре: смена ключа Yandex, Folder ID и ссылки/ID таблицы с записью в `.env` (доступ по паролю).

### Изменения в этой версии

- Зафиксированы зависимости и сценарий быстрого старта (venv, `requirements.txt`).
- Документация: README, `.env.example`, подсказки в UI; этот файл — **история версий**.
- Версия отображается в шапке сайдбара Streamlit (константы `APP_VERSION_*` в `web_gui.py`).
- Убрана возможность менять ключ API Яндекса и таблицу Google из обычного сайдбара — только через админ-панель.
